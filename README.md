## How to run
**Jupyter:** put all files in one folder, open `Sunday_Project.ipynb`, choose *Kernel > Restart & Run All*.

**Google Colab:** upload `Sunday_Project.ipynb`, then upload `sales_raw.csv` through the Files panel (same working folder). Run *Runtime > Run all*.

Requires Python 3 with `pandas` and `matplotlib` (both preinstalled in Colab). Paths are relative, and Part B reads `cleaned_sales.csv` created by Part A, so run Part A first.
